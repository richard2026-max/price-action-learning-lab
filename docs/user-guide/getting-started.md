# Price Action Learning Lab · 用户手册

## 一、启动与访问

双击 `start-backend.cmd`，浏览器打开 **http://127.0.0.1:8000**。

| 页面 | 功能 |
|---|---|
| 🎯 回放训练 | 逐根K线训练 + Predict First 判断锁定 |
| 🔍 候选扫描器 | 批量扫描历史数据并人工审核候选 |
| 📊 学习分析 | KPI 大屏 + 读图画像 + 错题本 + 盲测复评 |
| 💾 数据管理 | 数据集列表 + 合成数据生成 |

---

## 二、逐根回放训练（核心）

### 设置
1. 选数据源：合成演示 或 真实 SPY（需先运行 `data ingest-hfdl`）
2. 选交易日、训练模式（自由/严格/封存考试）、预热K线数
3. 点「开启逐根训练」

### 操作快捷键

| 按键 | 功能 |
|---|---|
| Space | 播放/暂停 |
| → | 下一根 |
| ← | 上一根（仅自由模式） |
| J | 提交判断 |
| T | 模拟下单 |
| M | 笔记标注 |

### Predict First 流程
1. 看到关键位置时按 **J**，在弹窗中回答十问（环境/结构/回调/bar counting/方向/理由/入场止损目标/概率自评）
2. 提交后判断**永久锁定**，系统候选自动揭晓供对比
3. 继续推进验证你的判断

### 模拟交易
按 **T** 开立模拟头寸：
- 选择方向（做多/做空）与订单类型（市价/限价/停止）
- 设定 Entry / Stop（失效点）/ Target
- 推进K线时自动撮合挂单、更新 MFE/MAE 并检查止盈止损触发
- 同根K线触及止损和目标时默认保守结算为止损（ADR-005）

### 右侧信息面板
- **关键价位**：前日 H/L/C、今日开盘、盘前 H/L、缺口
- **系统候选**：提交判断后解锁显示 19 类形态识别器输出
- **模拟持仓**：实时 MFE/MAE 与 R 倍数
- **已锁定判断**：当日全部判断历史
- **AI 对照复盘**：对已提交判断打开侧栏，查看原始判断、客观事实、原书/课件依据与教练诊断；不会改写原始判断

### AI 教练与课件知识库
1. 将原书 PDF/笔记放在仓库外的 `AlBrooks书`，将中文课件 PDF/MD/TXT 放在 `AlBrooks课件`。
2. 复制 `.env.example` 为 `.env`，按需设置 `PALL_AI_ENABLED=true`、`PALL_AI_API_KEY=...`；默认使用 DeepSeek `https://api.deepseek.com/v1` 与 `deepseek-chat`。
3. 首次调用会逐页解析并写入 `data/cache/knowledge_index.json`，之后按 mtime + 内容哈希增量更新；新增、修改或删除文件会自动同步。
4. API Key 只放本地 `.env`，不要提交 Git。未配置 AI 时，系统仍可展示知识库引用并明确提示未配置，不会调用远程模型。

## 三、候选扫描器

1. 选择数据源与日期范围
2. 可选指定 Detector 子集（留空扫描全部 19 类）
3. 点击「启动批量扫描」
4. 扫描完成后筛选候选列表（按 detector/审核状态/收藏/错题本）
5. 点击行选中候选，在底部抽屉查看 Evidence 并给出审核结论
6. 「打开回放 ↗」跳转到该日期的回放训练进行复核

---

## 四、学习分析与错题本

- **KPI 大屏**：训练会话数、已审核正反例、收藏与错题总数
- **读图画像**：宏观环境判断倾向分布
- **错题本归档**：集中展示所有标记为反例的案例及拒绝原因
- **盲测复评 (Blind Recheck)**：系统抽取历史已审候选（隐藏旧标签），你重新独立判断后对比前后一致性

---

## 五、真实 SPY 数据接入

1. 到 [hfdatalibrary.com](https://hfdatalibrary.com) 免费注册获取 API Key
2. 在项目根目录创建 `.env` 文件，填入 `PALL_HFDL_API_KEY=你的key`
3. 运行：
```bash
cd apps/api
.venv\Scripts\python -m app.cli data ingest-hfdl --start 2019-01-02 --end 2021-12-31
```
4. 回放页面切换数据源到「真实 SPY」即可开始训练

> 建议优先使用 2022 年之前的日期（合并磁带时期精度最佳）。
